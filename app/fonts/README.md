# Fonts

The two display fonts this app ships, both under the SIL Open Font License
version 1.1 (https://openfontlicense.org), which allows shipping them with
the app:

- **Anton-Regular.ttf** — Anton, by The Anton Project Authors
  (https://github.com/googlefonts/AntonFont). The bold condensed capitals of
  every cover title.
- **Pacifico-Regular.ttf** — Pacifico, by The Pacifico Project Authors
  (https://github.com/googlefonts/Pacifico). The neon script subtitles.

Nothing here is a Rockstar Games font, logo or artwork: the lettering is
entirely these two open fonts plus the app's own canvas drawing.
